# 精氨酸每天睡前吃有什么好处吗？

> 更新时间：2026-09-17 (UTC+8)

精氨酸在每天睡前吃是因为它里面的成分可以在睡觉的时候更好的进入到服用者的体内，能够让药效达到最佳的效果，让服用者可以更好的吸收，加快对劲病的治疗。精氨酸又称蛋白氨基酸，是氨基酸类化合物。本品在人体内参与鸟氨酸循环，促进尿素的形成，使人体内产生的氨经鸟氨酸循环转变成无毒的尿素，由尿中排出，从而降低血氨浓度。

## 精氨酸睡前服用的原因

因为我们在睡眠的时候，体内会生成的一氧化氮量要比白天或者运动时少，这个时候服用精氨酸的话，可以更好的发挥精氨酸的效果，提高它的营养价值。而相对夜晚的话，其他时间服用精氨酸则难以更好的展现它的效果。

精氨酸的用法用量

一般来说，成人精氨酸的日剂量约为3g。但静脉注射精氨酸通常为15-20g/次，缓慢滴加10%葡萄糖(4小时以上)。静脉滴注一次15-20g，于4小时内滴注完。

精氨酸的好处

- 1. 精氨酸在人体内参与鸟氨酸循环，促进尿素的形成，使人体内产生的氨经鸟氨酸循环转变成无毒的尿素，由尿中排出，从而降低血氨浓度；
- 2. 精氨酸具有较高浓度的氢离子，有益于纠正肝性脑病时的酸碱平衡；
- 3. 精氨酸也用于辅助测定脑垂体功能。口服用于精液分泌不足和精子缺乏导致的男性不育症；
- 4. 长期服用精氨酸的话能够加快身体恢复的速度，不过前提是根据医嘱进行服用；
- 5. 精氨酸在医学中还可以用于一些精神病的治疗，它对那些人们因血氨增加发生的精神病症状有很明显的治疗功效。

服用精氨酸的时候，一定要按时吃，不能有一顿没一顿的，依照药的医师叮嘱的，一天吃几回，尽可能不必少，并且在服药的情况下，最好是不能用茶叶茶吞服药品，那样哪些降低药品的医治的实际效果，服药期内还要留意饮食搭配需要口味淡。
