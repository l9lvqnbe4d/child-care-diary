# 极度厌恶自己的母亲是一种怎样的体验？

> 更新时间：2026-09-17 (UTC+8)

大学毕业后拼命工作攒了两年的钱，我终于从4S店把我价值百万的全新宝马X7开回了家。

去车管所上牌的时候，亲妈带着舅家的二表哥风风火火拦住我，逼我将车上在表哥名底下。

「方瑶 你现在太小，还没结婚。把车上到你哥名底下，以后违章什么的都让你哥处理，你也方便。」

我哥也放下伪装，扯起他一成不变的傲慢嗓音，居高临下地看着我，

「你嫂子刚生了孩子，正需要一辆大一点的车。你又没成家，买那么好的车干嘛？」

说罢他就掏出自己的身份证和驾驶证，扔在了办理行车证窗口的警官面前。

他戏谑地朝我翻着白眼，把我的证件收起全部塞进了我妈怀里。

然后他一把把我推到了地上，头和瓷砖地板接触的那一刻，瞬间鲜血横流，染红了那一大块白色地砖。

我妈对我的受伤什么反应都没有，依旧满面春风地拉着我哥在一边要求着警官尽快办理表哥我的X7在表哥名下的落户。

1

毕业三年，为了逃离家中雌竞母亲的控制，我拼命赚钱，同时做着五六份工作，只为了能够脱离原生家庭的苦海。

我的妈妈是一个典型的重男轻女的雌竞母亲。她从小就看我不顺眼，处处贬低、打压我的自尊心。

在我呱呱坠地的时候，她歇斯底里地抓着助产士的手，满产房都能听见她的谩骂声，

「把这个死丫头片子给我送走，我生的明明是个儿子！」

我妈怀我俩月的时候先兆流产，人都走到人流手术室门口了，因为害怕她还是选择回家保胎。

怀孕的时候她对不明性别的我充满了期待，买了许许多多小男婴的衣服以及婴儿用品。

但当发现我不是个带把的，她立刻变成了一个魔鬼，恨不得立刻让我去死。

我出生的第二天晚上，她趁我爸睡着，悄悄下床来到我的摇篮边，两只手死死掐住了我的脖子。

要不是我爸睡觉浅，察觉了她的不对劲，恐怕我根本活不过那天晚上。

父母都是那个年代的体制内职工，赶上了计划生育，不可能在保留双方工作的前提下再超生二胎。

我妈便将她所有的本应属于我的爱，全盘托付在了我两个舅舅家的两个表哥身上。

从我记事起，我妈一直毫无保留地在所有人面前夸赞两个表哥，同时也不忘借机拉踩、讽刺我。

「你看人家哥俩，又懂事又听话。再看看我家这个，娇生惯养一小祖宗，不知道是不是真把自己当公主了。」

而我的两个表哥，也可以在我妈面前肆无忌惮地嘲讽我。

「你一个丫头片子要什么可乐，白开水不够你喝的吗？」

「敢在你大哥面前要糖吃，跟个要饭的似的，你以为你是谁啊？给你脸了！」

「死丫头真觉得自己认字是白？装什么学生呢？充能！」

类似的嘲讽伴随了我的整个童年，我妈从来没有向着我说过一句。

她对我的好，也仅仅是因为她想要在外人面前给自己塑造一个好母亲的形象。

当着同事的面，她不会打压我，但会装出一个负责任的严母形象，无时无刻不去纠正我行为上的不良习惯，或者逼着我揠苗助长似的学习。

她给我留特别短的假小子发型，穿男孩子们穿小的衣服，甚至连一双红头的体操鞋都不愿给我买。

逛街的时候，她总是刻意避开着童装店，因为她才不愿给我花钱买新衣服。

每当我看到同龄的小女孩扎着漂亮的辫子，穿着五颜六色的漂亮裙子的时候，我妈总能一眼看穿我的想法。

「你配么？你那么邋遢的女孩，也不知道你哪里来的自信，还有脸羡慕人家，自己多土自己不知道么？」

而对两个表哥，她总是能倾尽所有。一个电话就能让她去陪逛一下午，刷爆她的工资卡给两个不学无术的侄子买最贵的衣服。

每当有人夸我，她总是找各种理由打压我、挑我的刺。

「就她还漂亮？土包子一个，打扮那么漂亮有什么用？勾引男人吗？」

所以我根本不敢在她面前抬头走路，生怕有人因为夸我而让我妈生气，最后受到责备发难的人还是我。

2

我妈兄弟姐妹六个，上面两个姐姐两个哥哥，下面还有一个妹妹，只有她通过高考改变了命运，进了城，有了体制内的工作。

但是也只有她生了一个女儿，我的姨妈舅舅们每家都有一个儿子。

因为没有儿子，所以她把所有的爱都倾注给了娘家的两个侄子。

她不顾一切地去讨好兄弟姐妹们，拼尽全力也要把侄子侄女外甥外甥女都带到城里安排工作。

尤其是两个侄子。

大舅家的大哥高考落榜后，我妈低三下四地到处托人给大表哥安排进了大专。

但当别人问起的时候，她总是说表哥上的是本科，给她老李家光宗耀祖。

当着我的面，即使心里对于大专一万个不满意，依旧当着我的面不停地夸赞表哥成绩优异。

「你看你涛哥，学习成绩那么好，现在可是大学生了，你得跟你大哥学。」

而大哥也一直理所应当地享受着我妈对他的偏爱。

每次大哥一来我家，我妈总是会买家里平常舍不得买的黑猪排骨给大哥吃，在餐桌上也不允许我在大哥吃饱前对排骨下筷子。

大哥对我的态度也和我妈一样，光明正大地当着所有人的面瞧不起我。

「你一个丫头片子吃什么排骨，就跟你吃上能考上清华北大似的。」

在我妈面前，两个表哥都可以肆无忌惮地对我说出最恶毒的话语。

上初中那年，我妈托关系把二哥也带进了城里安排他和我上了同一所中学，并且在我家暂住。

虽在同年级，但两个班级之间离得比较远，所以我几乎见不到他。

但我远远低估了他对我的伤害值。

如果说大哥对我的伤害都是摆在明面上的，那二哥则就是一个阴险奸诈的小人。

他暗地里拉拢我们班上的几个混子，在整个学校里传我的谣言。

「唉，你听说了吗？二班的那个方瑶看着挺老实，但是听说她一到周末就跟一群成年男人鬼混。」

「是是是，我也听说了，她表哥就在十五班，说经常大半夜跟她妈一起去酒吧捞她。」

「听说她还打过胎，其实也不奇怪，就她那一对大胸，肯定是为了勾引男人才长出来的。」

这样的谣言几乎充斥了我整个初中阶段。

起初我并没有在意这些谣言给我带来的影响，只是自顾自地埋头学习。

但是我慢慢发现不只是同学们在课堂和课下起哄，就连老师们看我都带上了有色眼镜。

同学们开我的玩笑、给我贴黄色谣言的标签时，没有任何一个老师制止。

而当我被隔壁班的几个大姐大堵到女厕所里薅头发的时候，班主任也只是轻蔑地说了一句，

「苍蝇不叮无缝的蛋，身正不怕影子斜，你应该反思你自己的不良行为，别总找别人的错误。」

同学们对我的校园霸凌愈演愈烈，最后连老师们都加入了施暴者的行列。

除了语言上的攻击与侮辱，有的男老师甚至会在下课后把我叫到办公室，关上门，对我做见不得人的事情。

每当我想要跟家里人哭诉在学校里的遭遇时，我妈总是会针对我摆出一副凶神恶煞的态度，

「你他妈的又犯骚了是不，你就是一把贱骨头，把我老脸都丢尽了，你还有脸哭上了」

「你再狡辩我就把你的嘴给你撕烂你信不？」

那一天，二哥带着他班里的几个小混混来我班找我的茬。

那几个杀马特当着我全班同学的面，在此起彼伏的起哄与讥讽声中，带着满脸的淫笑把我团团围住，然后每个人都上前去面向我伸出地狱中恶鬼的魔爪，将我校服衬衫里的文胸一把拽下。

在场的所有男生都如同发疯一般将他们罪恶的手掌伸向了我的前胸。

我蹲坐在地上，双手死死环绕在胸前，做出自我保护的动作，泪水如同决堤的大坝一般从眼角倾泻而出，拼命呼喊着乞求这一切快些结束。

直到两边上课铃打响，看热闹的人群才逐渐散去。

我依旧跪在地上，眼睛模糊到已经看不清楚周围的环境，那件被撕扯成两半的文胸被那些恶魔们挂在了走廊的栏杆上。

我的尊严也在那一刻被钉在了由铁栅栏组成的耻辱柱上面，那是我这一生都无法摆脱的噩梦。

3

我妈听说后，立刻放下了所有的工作来到了学校。

我本以为她会因为表哥这次做得太过分而向着我说话，而现实却狠狠扇了我一个大耳刮子。

她不分青红皂白，见了我立刻就用右手甩了我一个耳光。

我的左脸就像是被抹了辣椒油一般火辣辣地疼，耳边也开始出现延绵不断的金属耳鸣声，但我却连动都不敢动一下，只能任由泪水模糊眼前的一切。

「你他妈还有脸哭，自己干出那么犯贱的事情，败光了老娘的老脸，你看我今天不打死你这个小婊子！」

说完她就随手抄起墙角里的一把笤帚，脸上带着我分不清楚的恶意和怒意朝着我快步走来。

我吓坏了，直接朝教室最里面我的座位上走去，蜷缩在课桌底下，以为这样她就会碍于面子不会对我下死手。，。

我还是低估了她的战斗力。

她一手将我的桌子掀翻在地，连同周围三四个同学的桌子一起，全部撩在了地上，大家的书本和学习用品散落了一地。

我被她掀桌子的动作一下子摔在了地上，额头磕在水泥地板上，直接撞了一个大包，视线里一下子充满了各种黑白点组成的电视短线的画面，脑袋里嗡嗡作响，像是有几千只蜜蜂在我头顶周围乱飞。

扫帚抽打在我的后背和屁股上，锋利的高粱穗外壳在我的皮肤上留下了无数道红色的划痕，一时间又痛又痒。

我挣扎着朝着远处爬去，但还是一下子被她拽住了脚踝。

她拽着我的腿，在铺满散落的文具的地板上，像对待一只拖把一样将我的身体死死按在地上摩擦，把地上不知道是谁的文具、书本都给揉烂。

周围不断传来周围同桌的尖叫声，不是因为我妈对我下手太狠吓到了他们，而是我妈把他们的桌椅板凳还有课本文具全都掀翻在地给他们造成了损失。

但绝大部分人的脸上，挂着的都是看热闹不嫌事大的模样，讥讽与嘲笑声不绝于耳，甚至有人起哄让我妈打我打得更狠一点。

拖拽过后，我的脸颊上、脖子上、胳膊上、手心处、和肚子上全部都是摩擦完的破皮，鼻子里也因为我妈在我脸上的踢打充斥着血腥味。

直到上课铃响起，数学老师走进教室，看到教室里的一片狼藉，才喊来两个保安把我妈请了出去。
